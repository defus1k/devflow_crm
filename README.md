# 🚀 Nexora BotForge

**Nexora BotForge** — сучасна CRM-платформа та Telegram-бот для автоматизації роботи IT-команди, управління замовленнями та взаємодії між клієнтами, менеджерами й розробниками.

---

## ✨ Основні можливості

- 🤖 Telegram Bot на Aiogram 3
- 👤 Система ролей:
  - Owner
  - Administrator
  - Manager
  - Developer
  - Client
- 📦 Управління замовленнями
- 👨‍💻 Робочий кабінет розробника
- 👔 Панель менеджера
- ⚙️ Адміністративна панель
- 💬 Система повідомлень
- 📎 Обмін файлами
- 📊 Статистика
- 🔔 Сповіщення
- 🔐 Контроль доступу

## 🚀 Встановлення

### 1. Клонуйте репозиторій

```bash
git clone https://github.com/USERNAME/Nexora-BotForge.git
cd Nexora-BotForge
```

### 2. Встановіть залежності

```bash
pip install -r requirements.txt
```

### 3. Створіть `.env`

Скопіюйте `.env.example` у `.env` та заповніть усі необхідні змінні.

### 4. Запустіть застосунок

```bash
python main.py
```

---

## 🔒 Безпека

- Не публікуйте `.env` у GitHub.
- Використовуйте складні секретні ключі.
- Зберігайте токени лише локально або у GitHub Secrets.
- Регулярно оновлюйте залежності.
